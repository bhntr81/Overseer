# Internal development records

These files are the project's working history, kept for whoever continues the work. They are
not user documentation and are not kept current: they describe the state at the time each was
written, and they name the author's machine, paths, and terminal sessions.

- `prompts/`: the bounded task prompts given to coding agents, one per increment
  (`*_NEXT_PROMPT.md`). New ones go here.
- `DESCRIPTION.txt`: a program description as of 2026-11-10. Superseded by the
  [README](../../README.md); it predates native Windows support.
- `DEVTOOLS_INSTALL_RESULT.md`: a record of client tools installed on the author's machine.
- `ideas.txt`, `ideas/`, `future_ideas_and_architecture_roadmap.md`: notes and source images
  for ideas that were considered. None is a commitment or a description of what is built.

Elsewhere: `WORK_LOG.md` at the repository root is the chronological log, and
`HARDENING_BLUEPRINT.md` holds the engineering mandates agents follow. What is actually
implemented is in [docs/HARNESS_FRAMEWORK.md](../HARNESS_FRAMEWORK.md).
