# Raw-source intake policy

Keep original source material read-only and preserve its provenance. Never edit
or silently replace an original. If a new version or capture is needed, retain
the earlier original and add a separately named version with its own source ID
and retrieval details. Record the source title, URL or origin, author when
known, retrieval date, media type, and relevant limitations in the existing
[`research/sources.json`](../../sources.json) registry.

This prototype does not download or copy full external articles. The current
source registry records URLs and metadata; prior user-requested article images
remain in [`../../../ideas/`](../../../ideas/) with provenance in
[`../../../ideas/SOURCES.md`](../../../ideas/SOURCES.md). Do not duplicate those
images here.

If a source file is added later, preserve its acquired bytes and record a
checksum when practical. Treat read-only as a handling policy; file permissions
alone are not proof that a source has remained unchanged. Keep access and
copyright limits in mind when deciding whether a source may be stored locally.
